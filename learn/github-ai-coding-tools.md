## 概览

GitHub 热榜 6 个项目，其中 3 个是代码理解工具，AI 编程工具集体冲榜。

---

## 热门项目一览

### 1. Cline Skills

| 指标 | 数据 |
|------|------|
| 今日涨星 | +3,300 |
| 总星数 | 149,000 |

**核心功能：**
- 只用一个 `plmD` 文件，让所有AI 编程助手变强
- 不需要装任何插件
- 开发者用脚投票

**适用：** 所有 AI 编程助手通用

---

### 2. CodeGraph

| 指标 | 数据 |
|------|------|
| 今日涨星 | +2,400 |

**核心功能：**
- 预索引的代码知识图谱
- 不读代码就能理解整个项目
- 本地运行
- 帮 AI 助手省下大量 Token 调用

**价值：** 降低 Token 消耗，提升理解效率

---

### 3. Understand-Anything

| 指标 | 数据 |
|------|------|
| 总星数 | 21,000 |

**核心功能：**
- 把任何代码库变成可交互的知识图谱
- 像用地图导航一样理解代码
- 支持对着代码提问
- 支持 GitHub 等 20+ 平台

**特点：** 可交互式代码导航

---

### 4. AI演示文稿生成工具

**核心功能：**
- 说一句话就能生成专业 PPT
- 开源替代品
- 提供 API 可调用

**适合：** 新上网用户值得关注

---

### 5. NVIDIA LongLive

**出品方：** NVIDIA

**核心功能：**
- 用 FP4 量化做实时长视频生成
- 专业级压缩
- 并行推理速度和质量的平衡做得不错

**技术亮点：** FP4 量化 + 实时生成
